# 恐龙拼图 · AI 画图任务清单

这份清单给人或 AI 助手（例如 GPT）照着画图用。每一条是一张拼图图片。

## 给 AI 助手的说明（请严格按这个做）

1. 逐条按下面的「提示词」生成图片，**横版 3:2，1536×1024**（或更大的 3:2）。
2. 文件名必须和清单里的「文件名」**完全一样**（例如 `ai-3d-01.png`）。PNG、JPG、WEBP 都可以，扩展名用实际格式：`ai-3d-01.jpg` 也会被识别。
3. 把图片提交到这个仓库的 **`puzzle/images/`** 文件夹（和 `meadow.webp` 等放在一起）。单张不要超过 3 MB，太大请转成 JPG（质量 85）。
4. **不用改任何代码或清单**：游戏的 `puzzle/pictures.js` 已经登记了全部文件名，图片一放进去就会自动出现在对应分类里；没画的会自动隐藏。
5. 可以分批提交，画好多少提交多少。机器可读版本：`puzzle/ai-art/prompts.json`（字段 file / prompt / name / set）。
6. 如果某张图画出来有尖牙特写、打斗、吓人的表情或文字，请重画。
